# universe-fx-kit

Design test for a set of interactive effects inspired by githubuniverse.com: a snap-to-grid glyph cursor trail, nav text that decodes on load and hover-out, and a cursor-tracking cat on a rippling dot grid.

Dependency-free vanilla JS/CSS, original code and artwork. Respects `prefers-reduced-motion`.

Community project built with GitHub Copilot. Not a Microsoft or GitHub product.
